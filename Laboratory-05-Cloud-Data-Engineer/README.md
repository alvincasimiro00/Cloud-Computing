 Laboratory 5 — Cloud Data Engineer

 Mission Overview
Deployed an S3-compatible Object Storage server using MinIO and Docker. Configured a dedicated bucket for a photo-sharing application, uploaded test files, and documented the full workflow in GitHub.

 Objectives
- Distinguish between Block, File, and Object Storage
- Deploy containerized services using Docker and environment variables
- Access cloud interfaces through port forwarding
- Create and configure object storage buckets
- Maintain professional cloud documentation

 Tools Used
- Docker — container platform
- MinIO — S3-compatible object storage
- KillerCoda — cloud lab environment
- Git & GitHub — version control and portfolio
- Web Browser — console access

 Skills Learned
- Writing and executing multi-line Docker commands
- Mapping container ports for external access
- Managing object storage buckets and permissions
- Technical documentation using Markdown
- Cloud service deployment and verification
