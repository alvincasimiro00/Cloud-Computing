 Docker Deployment and Lifecycle Commands

| Command | What It Does |
|---|---|
| docker ps | Shows all containers that are currently running |
| docker stop my-nginx | Stops the running container named my-nginx |
| docker ps -a | Shows all containers, including the ones that are already stopped |
| docker rm my-nginx | Removes the container completely from the system |
