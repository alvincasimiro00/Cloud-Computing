Client Recommendations

 Client A — Startup Company
Recommended Platform: Amazon Web Services (AWS)

Recommendation:
AWS is the best choice for this startup. It offers a generous Free Tier that allows them to start building without upfront costs — critical given their limited budget. As they grow, AWS automatically scales to match their expansion, so they only pay for what they use as their user base grows. AWS also has the largest community and documentation, making it easier for small teams to learn and troubleshoot.

Three (3) Services the Client Could Use:
1. Amazon EC2 — to host their mobile application backend
2. Amazon S3 — to store app assets, user uploads, and static files
3. Amazon RDS — to manage their application database with automated backups

 Client B — University
Recommended Platform: Microsoft Azure

Recommendation:
Azure is the most practical choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure integrates natively with all of these — using the same accounts, licenses, and skills they already have. This means zero new training is needed, no complex identity setup, and potentially no extra cost through existing Microsoft agreements. It is the smoothest possible migration path.

Three (3) Services the Client Could Use:
1. Azure Virtual Machines — migrate existing Windows Server workloads to the cloud
2. Azure Active Directory — unified identity management, same as their on-premises setup
3. Azure SQL Database — host student information and administrative databases

 Client C — AI Research Company
Recommended Platform: Google Cloud Platform (GCP)

Recommendation:
GCP is the undisputed leader in AI and Machine Learning. It offers **TPUs** — Google's custom-designed AI accelerators — which deliver significantly faster performance at lower cost than standard GPUs available on other platforms. GCP also provides Vertex AI — a complete managed platform for building, training, and deploying AI models — plus BigQuery for massive-scale data analysis. This combination simply cannot be matched elsewhere.

Three (3) Services the Client Could Use:
1. Vertex AI — end-to-end AI/ML development platform
2. Compute Engine with TPUs — high-performance AI model training
3. BigQuery — analyze massive datasets quickly and economically

Client D — Global E-Commerce Company
Recommended Platform: Amazon Web Services (AWS)

Recommendation:
AWS is the best choice for a worldwide e-commerce platform because it has the most extensive global infrastructure  32 regions  placing servers closer to customers everywhere for faster page loads. AWS also offers proven reliability, automatic scaling during traffic spikes, and a complete suite of e-commerce-ready services. It is the most battle-tested platform for handling unpredictable global traffic while maintaining high availability.

Three (3) Services the Client Could Use:
1. Amazon EC2 with Auto Scaling — handle traffic spikes during sales events
2. Amazon S3 + CloudFront — fast global delivery of product images and static content
3. **Amazon RDS with Multi-AZ** — highly available database for transactions

Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Free Tier, low entry cost, broad community, easy scaling |
| Enterprise Organization | AWS | Mature security, compliance, and service breadth |
| Microsoft Environment | Azure | Native integration, unified identity, license benefits |
| AI / Machine Learning | GCP | TPUs, Vertex AI, BigQuery — purpose-built for AI |
| Kubernetes Deployment | GCP | Origin of Kubernetes; best managed experience |
| Global Web Application | AWS | Most regions, proven reliability, global CDN reach |
