# Amazon Web Services (AWS) — Research

## 📌 Brief Overview
**Amazon Web Services (AWS)** is the world's largest and oldest cloud service provider, owned by Amazon. Launched in 2006, it offers over 200 fully-featured services ranging from simple computing to complex enterprise infrastructure.

## 🌍 Global Infrastructure
AWS operates across **32 geographic regions** with 102 Availability Zones worldwide. Its data centers span North America, South America, Europe, Asia-Pacific, and the Middle East — providing the most extensive global coverage.

## 🖥️ Cloud Management Console
A web-based dashboard where users can access, configure, and manage all AWS services through a unified interface. It features organized service categories, search functionality, and resource monitoring.

## ⚙️ Four (4) Core Services
1. **Compute** — Amazon EC2 (Elastic Compute Cloud — virtual machines)
2. **Storage** — Amazon S3 (Simple Storage Service — scalable object storage)
3. **Database** — Amazon RDS (Relational Database Service)
4. **Networking** — Amazon VPC (Virtual Private Cloud — isolated network environment)

## ✅ Three (3) Advantages
1. **Widest range of services** — over 200+ services covering every possible infrastructure and application need
2. **Largest global infrastructure** — highest availability, reliability, and low-latency performance worldwide
3. **Generous Free Tier** — many services are available for free for 12 months, making it ideal for learning and startups

## 🏢 Typical Enterprise Use Cases
- Hosting websites, web apps, and mobile backends
- Big data analytics, AI/ML development, and data warehousing
- Enterprise resource planning and business applications
- Auto-scaling infrastructure for seasonal or rapidly growing workloads
