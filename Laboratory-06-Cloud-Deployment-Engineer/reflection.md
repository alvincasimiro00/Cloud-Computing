# Mission Reflection

## How does `docker-compose.yml` make an engineer’s job easier?

Docker Compose makes the work easier because we can put the needed settings in one file. Instead of typing many commands one by one, we can use one command to start the whole system. It also helps avoid mistakes and makes the setup easier to repeat.

## What happens with indentation errors in YAML?

YAML needs the correct spacing and indentation. If the spacing is wrong or a Tab is used, the file may not work and can show an error. This is because the indentation tells YAML how the settings are organized.

## Why use environment variables?

Environment variables are used to store settings such as passwords and usernames. They are useful because we don't have to put these details directly in the code. They also make it easier to change settings without changing the whole application.

## Deploying enterprise software in minutes — how did it feel?

It felt convenient because we were able to set up Nextcloud and the database much faster than doing everything manually. I learned that Docker can make the setup process easier and more organized.

## How has my understanding evolved since Mission 1?

Before, I thought cloud computing was mostly about storing files online. After doing the activities, I learned that it also involves servers, databases, networks, and applications. I now understand better how these different parts work together to provide a cloud service.
